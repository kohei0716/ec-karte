# ECカルテ

受注CSVから、在庫の問題点と「次にやること」を出す無料ツールです。

**→ [ツールを開く](https://kohei0716.github.io/ec-karte/)**
**→ [診断レポートのサンプルを見る](https://kohei0716.github.io/ec-karte/sample_report.html)**

## できること

カートの管理画面から出力した受注明細CSVを読み込むと、以下を出します。

- 売上・粗利・粗利率・客単価・在庫日数の集計
- 粗利ランキング（売上順ではなく粗利順）
- カテゴリ別の在庫日数
- 商品ごとの判定 ── 欠品／要追加／品薄・様子見／滞留／適正
- 明日やること ── 追加発注・値引き・欠品対応・薄利商品の指摘

## データは送信されません

すべてブラウザの中だけで処理します。サーバーへのアップロードも保存も行いません。ページを閉じた時点でデータは消えます。

## 対応

- カート: Future Shop / Shopify / カラーミー / MakeShop / 楽天 / Yahoo!ショッピング など、CSVを出力できるもの
- 文字コード: Shift_JIS / UTF-8（自動判定）
- 必須の列: 商品名、金額または単価
- あると精度が上がる列: 受注日、商品コード、カテゴリ、数量、原価、在庫数

## 判断の考え方

**追加発注は、単品の在庫日数ではなくカテゴリ全体の在庫を見てから決めます。**

単品の在庫日数が10日でも、同じカテゴリ全体に200日分の在庫があるなら、そこで追加すると余っている在庫の上に積むことになります。このツールは両方を突き合わせて「追加する」「品薄だが見送る」を分けて出します。

**将来の売上予測はしません。**

需要予測の精度を実データで検証したところ、誤差±33%で発注判断に使える水準ではありませんでした。外れた予測は誤った発注を生みます。確定したデータの解釈と、そこから導ける判断だけを出します。

## 構成

| ファイル | 中身 |
|---|---|
| `index.html` | 画面 |
| `core.js` | 分析ロジック（DOM非依存） |

| `sample_report.html` | 診断レポートのサンプル |
